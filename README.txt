This project represents a graphics/game engine, developed using C++ and OpenGL API, which allows the app to utilize GPU resources for rendering complex 3D scenes, with different and multiple lighting techniques (following the rasterization pipeline), shadow maps, materials and textures + simple first person controls.

NOTES:

-The project takes some time to load initially due to precalculating Tangent and Bitangent vectors for normal texture calculations.

-When inside the app, press n to activate normal textures.

-There are also multiple other functionalities -> check keyboardCallback function from main.cpp
